# Kosh · Онбординг Атвинты

Сайт: https://90juli-ship-it.github.io/Kosh/

Версия 1.4.2: единое оформление меню отделов и сортировки, управление с клавиатуры и адаптация к экрану; убрана жёлтая звезда из баннера; новая главная с поиском, быстрыми ссылками на сотрудников и фотографии, сохранёнными материалами и подсказками чата. Библиотека поддерживает список и карточки, сортировку и сброс фильтров. Фирменное оформление, адаптивная версия и навигация кнопкой «Назад». В каталоге 24 проверенные ссылки.
общий поиск в каталоге и чате учитывает слова «найти», «покажи», окончания и синонимы.
Текущий шаг и прогресс находятся на первом экране; мобильная навигация адаптивна.

Портал адаптации: главная, маршрут, база знаний, задачи и чат-помощник.

## Размещение

`index.html` — автономная версия сайта. Стили, скрипты, фотографии и шрифты встроены
в файл, поэтому интерфейс не зависит от хостинга ChatGPT или Google Fonts.
GitHub Pages публикует ветку `main`, папку `/ (root)`.

Настройки: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
Последующие изменения `index.html` публикуются автоматически средствами GitHub Pages.

## Исходники

`source.zip` содержит отдельные HTML, CSS и JavaScript, локальные фотографии,
шрифты, описание источников и проверки. Для разработки распаковать архив и
выполнить `node preview.mjs`; открыть http://127.0.0.1:4173/.
В архиве также сохранён альтернативный workflow для публикации папки `dist`
через GitHub Actions. В текущей конфигурации используется корневой автономный файл.

## Данные и авторизация

Сайт общедоступен. Содержимое закрытых документов не копируется; при переходе
в Чавошу пользователь проходит её собственную авторизацию.
Прогресс, заметки, закладки, контакт наставника и история чата хранятся только
в браузере. При смене адреса автоматически не переносятся.

Чат отвечает по локальному каталогу ссылок. Языковая модель и чтение закрытых
документов не подключены. Маршрут и оценки времени демонстрационные.

Визуальные материалы предоставлены пользователем как скриншоты сайта atwinta.ru.
Шрифт Manrope используется по SIL Open Font License 1.1; лицензия лежит рядом
в `Manrope-OFL.txt`. Подробности в `ASSETS.md` внутри архива исходников.
